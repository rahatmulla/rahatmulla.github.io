02 — Internship

R&D Intern, Leap Interactive

Four projects built for an AI and event-technology studio — spanning desktop software, computer vision automation, a live control interface, and an image pipeline for drone light shows.

Company Leap Interactive Artificial Intelligence Developing Services LLC, Dubai Role Computer Science Engineering Intern, Engineering & Design Duration Feb – Jun 2025
This work was built under an employer confidentiality and IP-assignment agreement, so the source code stays private — the write-ups below describe what each system does and how it was built, the way the internship report presented it.
CHAPTER 1

AI Photobooth Frame Generator

A PyQt5 desktop app for designing event photobooth frames — logo placement, colour extraction from brand assets, 8 frame layouts, and custom captions. Version 1 added OpenAI's DALL·E to generate theme artwork from a plain-text event name, blending AI backgrounds with manual editing.

PyQt5PillowOpenAI DALL·E
CHAPTER 2

180° Photobooth GIF System

An automated pipeline that watches a folder for new 180° booth captures, corrects lens distortion, overlays branding, uploads the finished GIF to Google Drive, and generates a QR code so guests can scan and download instantly.

OpenCVGoogle Drive APIqrcode
CHAPTER 3

Smart Robot Control Panel

A real-time web dashboard for issuing commands to event robots — live connection status, an authenticated login flow, and animated feedback for each command, sent asynchronously to the robot's API endpoints.

HTML/CSS/JSFastAPIREST
CHAPTER 4

Image Pipeline for Drone Visuals

A batch pipeline that removes backgrounds, detects and crops around faces, enhances contrast and colour, then samples the image into a point grid — exporting SVG vector art and JSON/CSV coordinate files ready to feed drone light-show formation software.

OpenCVrembgMatplotlib
